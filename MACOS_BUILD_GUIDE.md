# Packaging and Building WboxAI for macOS

This guide provides step-by-step instructions on how to build and package WboxAI into a native macOS Application Bundle (`wboxai.app`) using PyInstaller.

---

## 📋 Prerequisites

Before building the application, ensure the following tools are installed on your macOS machine:

1. **Python 3.8+**: Recommended to be installed via [Python.org](https://www.python.org/downloads/) or [Homebrew](https://brew.sh/).
2. **Xcode Command Line Tools**: Needed for compiling C-based dependencies (e.g., PyAudio/sounddevice core dependencies if needed).
   Install it by running the following command in Terminal:
   ```bash
   xcode-select --install
   ```

---

## 🛠️ Step-by-Step Build Instructions

We have provided a helper shell script [`build_mac.sh`](file:///c:/Users/Jashuva/Desktop/interview-copilot/build_mac.sh) to handle the setup, dependency resolution, and build stages automatically.

1. **Open Terminal** on your Mac.
2. **Navigate to the WboxAI project root directory**:
   ```bash
   cd /path/to/interview-copilot
   ```
3. **Make the build script executable**:
   ```bash
   chmod +x build_mac.sh
   ```
4. **Run the builder script**:
   ```bash
   ./build_mac.sh
   ```

The script will automatically create a python virtual environment, install the required libraries (including `PyQt6`, `mss`, `sounddevice`, and `pyobjc-framework-Cocoa`), and compile the application.

## 🚀 Deliverables & Installation

Once the build successfully completes, the deliverables are located in the `dist/` directory:
1. **Application Bundle (`dist/wboxai.app`)**: The raw compiled Mac application.
2. **Disk Image (`dist/wboxai.dmg`)**: A standard macOS disk image installer.

### To Install and Run via DMG:
1. Double-click `dist/wboxai.dmg` to mount the disk image.
2. Drag the **WboxAI** app icon into the **Applications** folder link.
3. Open it from your Applications folder (or run `open /Applications/WboxAI.app`).

### To Run Directly from dist/:
* **Terminal**: Run `open dist/wboxai.app`.
* **Finder**: Navigate to `dist/` and double-click `wboxai.app`.

## 🔒 Security & Permissions (Important)

### 1. Gatekeeper Bypass (Unsigned App Warnings)
Because the executable generated by PyInstaller is unsigned by default, running or sharing it on another Mac may trigger a macOS Gatekeeper popup:
> *"wboxai.app cannot be opened because the developer cannot be verified"*

To bypass this restriction, clear the quarantine attribute on the app folder by running:
```bash
xattr -cr dist/wboxai.app
```

### 2. System Permissions
WboxAI relies on system-level captures (screen monitoring, microphone recording). When the app is launched for the first time, macOS will trigger standard permission dialogs asking for:
* **Microphone Access**: Required for capturing the Candidate's voice.
* **Screen Recording Access**: Required for capturing screen states and watching presentation frames.

Ensure you grant these permissions in **System Settings > Privacy & Security**. If the application UI loads but doesn't receive stream updates, verify these checkboxes are toggled on.

## 🔍 Troubleshooting

### Error: `pyaudiowpatch` not found
This package is Windows-only for WASAPI loopback support. On macOS, the system is designed to skip imports of `pyaudiowpatch` and fall back to native virtual inputs (such as [BlackHole](https://github.com/ExistentialAudio/BlackHole) or [Soundflower](https://github.com/mattingalls/Soundflower)) for capturing system sound/speakers. Make sure you do not manually try to install `pyaudiowpatch` on Mac.

### Missing virtualenv command
If python virtual environment creation fails, install/ensure the standard python venv module:
```bash
python3 -m pip install --user virtualenv
```
